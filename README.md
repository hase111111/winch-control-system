# winch-control-system
ワイヤ式急斜面移動支援システムのソースコードです．

## Build

### VSCode Tasks
タスクパレットから `CMake: Build` を実行してください．

### Shell Script
```bash
/home/taisei/winch-control-system/bash/build.sh
```

### Manual (CMake)
```bash
cmake -S /home/taisei/winch-control-system -B /home/taisei/winch-control-system/build
cmake --build /home/taisei/winch-control-system/build
```
